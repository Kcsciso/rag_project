### v10 关键发现

| 发现 | 详情 |
|------|------|
| ✅ 代码精简指令对部分用例生效 | E04 首次通过 — 没生成 class Pose 定义 |

### 结论

v10 的 3 项 LLM 微调达到了"边际改善"效果：
- **代码精简指令**对部分用例有效 (E04 ✅) 但 7B 模型执行不稳定
- **Guardrail** 成功减少了代码截断硬断言 (10→9)
- **max_tokens=2560** 在 8192 上下文限制下已达上限，进一步增加会导致更多 vLLM 400 错误

**后续方向**: 
1. 将 vLLM `--max-model-len` 从 8192 提升至 12288（为 max_tokens=3072 腾空间）
2. 将代码精简指令从 System Prompt 移至更强约束位置（如 user message 末尾的硬指令）
3. 模型升级 7B→14B 是突破代码截断瓶颈的根本方案
